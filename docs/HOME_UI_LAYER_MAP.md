# 门店首页分层（864 × 1536）

原设计图是压平的合成图。本页只从其中提取不含经营示例值的画面片段；卡片底色和边框由 CSS 绘制，数据由 `buildHomeDashboardModel(app)` 填入。不要把整张设计图或带示例数字的裁片重新叠在首页。

| 区域 | 固定画面 / 文案 | 运行时内容 | 点击 |
| --- | --- | --- | --- |
| 餐厅场景 | `scene-clean.png`（原图 y=95 以下保留，上方用无字木纹补齐） | 无 | 无 |
| 顶部 | 状态卡底、天气/资金/星级图标及栏目名 | 游戏日、时钟、营业状态、余额、评价分、等级、进度 | 设置→更多 |
| 四张数据卡 | 卡底、图标、栏目名 | 当日收入、利润及趋势、满意度、员工人数和状态 | 经营 / 员工 |
| 今日机会 | `opportunity-header.png`、商圈建筑上部、空白卡底 | 机会标题、建议、商圈名、标签、操作文字与目标页 | 按实际建议进入相应页 |
| 门店成长 | `growth-header.png` 和四个固定功能按钮 | 下一阶段、进度值与进度条 | 装修 / 员工 / 研发 / 经营 |
| 店内动态 | `feed-header.png`、按角色选择的头像素材 | 员工姓名、角色、对话、时间 | 员工 |
| 商圈情报 | `market-header.png`、栏目名 | 热度、主力客群、外卖需求、竞争强度 | 经营 |
| 今日日程 | `schedule-header.png`、当前规则定义的时间和事项名 | 完成/进行中/未开始状态 | 经营 |
| 底部导航 | `nav-home.png` 为门店选中状态的固定图 | 选中页及点击目标 | 五个一级入口 |

静态切片位于 `client/mobile/assets/home/`。所有区域使用设计稿坐标按 864 × 1536 换算；`HomePage.js` 保留 `home-page` 画布节点，开发用排版工具仍可在其上放置组件。

设计图上的“第28天、12:15、¥86,240、¥6,820、4.7分、68%”只是示例，未写入成品。当前 `DemoSeed.js` 仅在没有门店存档时提供试玩初值，不能作为静态图片内容。

限制：压平的设计图没有空白状态卡和无字卡片源图；本次用 CSS 还原这些底板。顶部无字木纹属于补片，与原设计图可能存在细微纹理差异。日程事项目前来自 `HomeDashboardModel.js` 的固定规则，若以后做可编辑日程，再把事项名也改为运行时数据。
