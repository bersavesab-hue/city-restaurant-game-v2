# 餐饮底层联动实施计划（2026-09-18）

本轮目标：直接完成用户要求的底层联动，不继续堆页面。

- 城市地图扩展到 10 个经营区域，并为前端缩放/拖拽保留统一坐标模型。
- 顾客分群扩展并与商圈客群结构、时段、价格敏感度、品质敏感度、等待耐受、消费能力联动。
- 时间系统正式接入 Android 运行入口，持续驱动小时/日级经营循环。
- 增加现实经济基准配置层：食材、工资、租金、能源、配送、装修/设备等统一通过基准指数与游戏动态系数组合，而不是页面写死价格。
- 增加价格弹性：涨价/降价对不同客群流失与需求提升不同，并继续影响客流、销量、库存、排队、评价与复购。
- 场所类型扩展：临街店、商场店、社区店、校园店、景区店、工业园店、农家乐、山庄、别墅私厨、纯外卖厨房等。
- 山庄、别墅私厨使用不同的场所适配系数与目标客群，不作为普通门店换皮。
- 经济周期、区域消费、竞争强度与经营场所适配进入同一需求计算链。

该文件用于记录本轮直接修改范围。
