# 餐饮 V2 五个一级页面视觉蓝图 1.0

## 0. 定稿原则

本文件以已确认的五张 864×1536 一级页面参考图为母版：

- 城市
- 门店
- 经营
- 员工
- 更多

不重新创造另一套视觉语言。

唯一需要统一的冲突已经解决：五个页面全部使用城市参考稿的 Global HUD。

页面只负责 Page Content；Global HUD 与 Global Nav 属于 AppShell。

## 1. 共同视觉语言

五页统一：

- 深蓝 / 蓝色公共外壳
- 金黄色主操作、选中态
- 暖色餐厅/城市主视觉
- 大面积暖白内容底板
- 16-20级圆角体系
- 彩色圆形/方形功能图标
- 重点数据大字号深蓝
- 成功绿色、警告橙色、异常红色
- 页面标题白色大字覆盖在主视觉上
- 一级页面不使用后台管理系统式灰色表格

图片中禁止烘焙动态金额、人数、等级、日期、商圈数量、门店名称等业务数据。

## 2. 公共组件

正式一级页只允许从以下组件体系组合：

- PageHero
- SectionHeader
- KpiStrip / KpiCard
- FilterTabs
- SearchField
- StatusChip
- ActionCard
- ImageFeatureCard
- TaskRow
- EntityCarousel / EntityCard
- DataList / ListRow
- MapViewport
- MapFilterBar
- DetailSheet
- PromoBanner

页面可以有专属布局，但不得重新制造功能相同、视觉不同的第二套基础组件。

## 3. 城市

定位：扩张、商圈、选址、房源机会。

### 顺序

1. 城市标题/区域统计
2. 商圈状态筛选
3. 大型城市地图
4. 当前商圈 DetailSheet
5. 今日机会

### 保留参考图特征

- 地图必须是页面绝对主视觉
- 商圈标签直接锚定地图
- 当前商圈有清晰选中状态
- 地图右侧保留缩放/定位
- DetailSheet 保留6项商圈指标
- 今日机会最多首屏展示3项

### 适配

Compact：底部详情Sheet，地图至少保留约42% Page Content可见面积。  
Medium：地图比例提高。  
Expanded：详情可改为地图右侧面板，避免平板下方大面积空白。

## 4. 门店

定位：集团门店组合管理，而不是单店经营后台。

### 顺序

1. 门店管理 PageHero
2. 集团经营4 KPI
3. 旗下门店 + 状态筛选 + 新开门店
4. 门店 EntityCarousel
5. 今日待办
6. 门店管理功能4入口

### 固定4个管理入口

- 装修布局
- 门店设施
- 租约管理
- 开店准备

门店数量必须0..N动态渲染，不允许把参考图中的4张门店卡写死。

## 5. 经营

定位：经营驾驶舱。

### 顺序

1. 经营中心 PageHero
2. 4个经营 KPI
3. 今日待办
4. 6个核心经营模块
5. 排行榜与荣誉
6. 研发菜品

### 六个核心模块固定

- 菜品与菜单
- 供应链与库存
- 财务资金
- 顾客与会员
- 营销与渠道
- 经营数据

Compact/Medium使用2列大图卡；Expanded可使用3列。

经营页不再继续增加第7、第8个大图模块。新增低频系统只能进入对应二级页或更多。

## 6. 员工

定位：人物和团队管理。

### 顺序

1. 员工管理 PageHero
2. 4个人力 KPI
3. 4个员工操作入口
4. 当前最紧急缺员/排班提醒
5. 员工列表
6. 列表搜索 + 分类筛选

### 四个操作入口固定

- 招聘员工
- 排班与产能
- 培训提升
- 晋升考核

员工列表使用高密度 ListRow，不为每个员工做大卡片。

Compact使用单列高密度列表；Expanded可变成左列表 + 右员工详情。

## 7. 更多

定位：低频品牌成长与游戏服务中心，不是杂物箱。

### 顺序

1. 更多 PageHero
2. 品牌与成长 4项
3. 顾客与安全 3项
4. 游戏服务 3项
5. 品牌氛围 PromoBanner

### 品牌与成长

- 连锁管理
- 长期品牌基建
- 排行榜
- 荣誉殿堂

### 顾客与安全

- 会员营销
- 评价反馈
- 合规中心

### 游戏服务

- 设置
- 存档管理
- 帮助与反馈

这10个一级入口已经足够；其他功能不要继续往更多页堆。

## 8. 响应式规则

### Compact <600

- KPI最多2列
- 操作入口通常2列
- 大图模块2列
- 门店使用横向Carousel
- 员工使用单列Dense List
- 城市使用底部Detail Sheet

### Medium 600-839

- KPI允许4列
- 操作入口4列
- 经营大图仍以2列为主
- 门店仍可Carousel

### Expanded >=840

- Global Nav切左侧Rail
- Page Content获得更多横向空间
- 经营核心模块3列
- 门店可从Carousel切Grid
- 员工可Split List/Detail
- 城市详情可从Bottom Sheet切Side Panel

不是把手机页面等比放大。

## 9. 正式视觉资源

资源计划已写入 PrimaryVisualResourcePlan。

### 共享

- HUD门店图槽
- HUD箭头
- 6种天气状态
- Pause / Play
- 资金 / Plus / 等级 / 评分
- 5个一级导航图标

### 城市

- 1张完整城市地图
- 20个商圈缩略图起步
- 3个地图控制图标
- 6个商圈指标图标

### 门店

- 1张Hero
- 12张起步门店外观池
- 4个管理功能图标

### 经营

- 1张Hero
- 6张核心模块封面
- 2个次级入口图标

### 员工

- 1张Hero
- 4个员工功能图标
- 40张起步员工头像池

### 更多

- 1张Hero
- 10个功能图标
- 1张品牌氛围Banner

这些是第一套正式资源基线；动态数据增长不得导致复制一整套UI图片。
