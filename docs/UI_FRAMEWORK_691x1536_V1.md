# 691×1536 UI Framework V1

## 1. 母版

当前唯一手机 UI 母版：691 × 1536。

## 2. 六段框架

| 区域 | Y | H |
| --- | ---: | ---: |
| HUD | 0 | 103 |
| Hero | 103 | 128 |
| Filters | 231 | 58 |
| Map | 289 | 716 |
| Detail | 1005 | 394 |
| Navigation | 1399 | 137 |

CSS 不再用一堆互相覆盖的 media query 去改变六段比例。

外壳使用 103 / 1296 / 137 三行比例，城市页内部使用 128 / 58 / 716 / 394 四行比例。

## 4. 字体

字体顺序固定：

Noto Sans SC → PingFang SC → Microsoft YaHei → system-ui → sans-serif。

只允许五档字重：

500 / 600 / 700 / 800 / 900。

主要字号参考：

- HUD主信息 22
- HUD副信息 14
- HUD时间 28
- 页面标题 38
- 页面副标题 16
- 筛选 16
- 地图标签标题 18
- 地图标签副信息 14
- 详情标题 24
- 详情正文 14
- 详情按钮 18
- 指标标题 14
- 指标数字 18
- 今日机会标题 20
- 机会卡标题 14
- 机会正文 12
- 底栏 22

运行时字号按 691×1536 的宽高比例取较小值，避免宽屏把字体放大。

## 5. 当前阶段禁止事项

- 禁止接正式图片。
- 禁止接业务动态数据。
- 禁止为了某台手机改一级框架。
- 禁止图标原图尺寸决定容器尺寸。
- 禁止恢复旧 ui-assets / CityMapVisualLayout / CityPageModel。
- 禁止用旧测试约束新框架。

框架实机通过后，下一阶段才开始资源填充和数据绑定。
