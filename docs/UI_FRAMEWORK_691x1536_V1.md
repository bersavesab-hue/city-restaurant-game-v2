这一阶段只允许校准框架、组件盒和文字基线；正式图片与业务动态数据仍然禁止接入。

## 9. 当前禁止事项

- 禁止接正式图片。
- 禁止接动态业务数据。
- 禁止添加 @media 改变当前框架和组件位置。
- 禁止图标原图尺寸决定容器尺寸。
- 禁止组件因为文本更长而改变自身宽高。
- 禁止恢复旧 CityPage / CityPageModel / CityMapVisualLayout / ui-assets。
- 禁止底栏激活项通过 margin 变大。

下一阶段必须先通过框架APK实机复核，再进入正式资源填充。
