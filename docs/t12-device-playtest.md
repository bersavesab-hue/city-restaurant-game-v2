## A — 安装、启动、首页与基础触控
目标：先确认 APK 在真实 Android 设备上可以正常进入并完成最基础操作。

必测：
- 安装/覆盖安装成功；
- 冷启动进入首页，无白屏、黑屏、崩溃、无限加载；
- 首页顶部状态、门店概览、成长卡、五个一级入口均能读取真实数据；
- 主要按钮可点，触控热区与视觉位置一致；
- 底部导航、返回行为无死路；
- 文字无明显截断、遮挡、重叠；
- 刘海/挖孔/圆角/底部手势区不挡关键按钮。

通过条件：
- 0 个阻断问题；
- 首页没有“看得到但点不到”的入口；
- 没有必须滚动才能看到本应固定显示的核心控件。

## B — 核心经营全链
按真实玩家顺序完整走一次：

1. 采购 / 库存
   - 选原料 → 供应商 → 数量 → 报价 → 下单；
   - 取消/配送状态正确；
   - 入库批次、库存数量、新鲜度变化正确。
2. 菜品
   - 菜单、详情、价格、配方；
   - 未解锁功能正确锁定；
   - Lv.5 后研发入口按规则开放。
3. 员工
   - 详情、招聘、培训、排班、薪资；
   - 操作后人数、工资和服务能力真实变化。
4. 活动
   - Lv.3 前锁定；
   - Lv.3 后可选活动；
   - 成本、持续时间、效果、冷却有反馈。
5. 装修 / 设施
   - 可查看、购买/升级；
   - 资金与设施状态真实变化；
   - 不出现旧自由摆放入口污染首发流程。
6. 营业与结算
   - 暂停、1×、2×、4×；
   - 客流、订单、库存消耗、收入、评价均真实变化；
   - 日结中的采购、工资、租金、营销等进入现金流。

通过条件：
- “状态读取 → 操作 → 业务处理 → UI反馈 → 保存恢复”全链贯通；
- 不存在假按钮、假数据、旧入口或重复接口。

## D — 成长目标与玩家可理解性
从新档真实推进，重点观察：
- Lv.1–3「街坊立足」目标是否看得懂；

- 真机阶段若节奏有问题，优先修提示和操作路径，再决定是否改经济参数。

## 问题等级
- 阻断：崩溃、无法进入、数据丢失、核心链路无法继续。
- 严重：资金/库存/结算/存档错误，主要按钮失效，大面积遮挡或无法操作。
- 一般：局部布局、文案、反馈、边界流程问题，但可继续游玩。
- 体验：看不懂、步骤烦、反馈弱、目标感不足。
