# 商店文案草案

## 应用名称
城市餐饮创业

## 一句话介绍
从一家小店起步，自己选址、装修、招人、研发菜品，逐步经营成跨区域餐饮品牌。

## 短介绍
真实经营逻辑驱动的餐饮模拟游戏。选商圈、签租约、做装修、管员工、研究菜品、控库存、做会员、冲榜拿奖，再从单店扩张到连锁与中央厨房。

## 完整介绍
《城市餐饮创业》是一款以“真实经营闭环”为核心的餐饮模拟游戏。

你将从一家资金有限的小店开始，亲自决定门店选址、租约、装修布局、员工配置、菜单结构、采购库存和营业节奏。顾客会根据价格、品质、等待时间、环境和口碑做出不同选择，员工会产生疲劳和成长，食材会过期，租约会到期，经营中的每个环节都会影响最终利润。

当门店逐渐成熟后，可以继续解锁会员经营、奖项竞争、第二门店、连锁品牌、中央厨房、区域扩张和长期品牌基建。

主要内容：
- 商圈与铺位选择；
- 真实租约与经营成本；
- 可拖放的门店装修布局；
- 员工招聘、培训和晋升；
- 正式菜品与自主研发菜品；
- 食材品质、库存、供应商和采购；
- 顾客满意度、熟客、会员与口碑；
- 营收、成本、利润和长期经营报表；
- 奖项、排行榜和荣誉系统；
- 多门店、中央厨房和区域扩张。

当前版本仍属于 Playtest 测试阶段，重点用于验证长期经营、数值平衡、手机 UI 和设备性能。
