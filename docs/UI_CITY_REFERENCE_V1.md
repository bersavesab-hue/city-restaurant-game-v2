# 餐饮 V2 城市页参考坐标规范 1.0

## 1. 唯一母版

城市一级页唯一视觉母版为用户确认的 **864 × 1536** 成品图。

以后城市页不再凭感觉调整比例；所有位置先对照本文件，再进行多尺寸适配。

## 3. 不同手机的适配方式

母版坐标不是把所有手机强行缩成 864 × 1536。

运行时遵循 **固定结构 + 地图吸收高度差**：

- Global HUD：结构、内容顺序、字体层级固定。
- 城市 Hero：结构固定，只允许受控字号压缩。
- 五筛选：单行五等分，不允许换成两排。
- Detail Sheet：信息结构固定；极窄屏只允许内部压缩。
- Global Nav：五等分固定。
- **不同手机多出来或少掉的纵向空间优先由地图区域吸收。**
- 不使用整页 transform: scale。
- 不按图片原始宽高把按钮、文字一起拉伸。

## 4. 字体层级

运行时全部从 Design Tokens 读取，不允许页面自己定义一套字号。

层级固定为：

- 页面大标题：32px 级，900 字重
- 页面副标题：14px 级，600 字重
- HUD 主信息：15–22px 级
- 筛选文字：14px 级，800 字重
- 商圈标签标题：13px 级，900 字重
- 商圈标签状态：10px 级，800 字重
- 详情标题：22px 级，900 字重
- 详情正文：13px 级，600 字重
- 指标标题：11px 级，700 字重
- 指标数字：18px 级，900 字重
- 今日机会标题：18px 级，900 字重
- 机会卡标题：12px 级，900 字重
- 机会卡正文：10px 级，600 字重
- 底栏文字：13px 级，800/900 字重

中文字体栈固定优先：

Noto Sans SC → PingFang SC → Microsoft YaHei → system-ui。

## 5. 排版纪律

- 所有标题左对齐基线统一。
- 数字使用 tabular-nums。
- 金额、时间、等级、评分禁止省略号。
- 正文最多两行的地方必须固定 line-height，不允许卡片随文案无限长高。
- 图标与文字之间只使用 4 / 8 / 12 / 16 / 20 / 24 / 32 间距体系。
- 圆角只使用 8 / 12 / 16 / 20 / 24 / pill。
- 主要按钮高度不小于 48。
- 地图控制按钮固定同尺寸、同间距、同右侧锚点。
- 图片只能 cover / contain，不允许非等比拉伸。

## 6. 素材接入

当前已确认可直接采用的视觉资源继续按既有 image slot 接入。

图片只负责：

- 底板
- 图标
- 地图
- 标签框
- 商圈缩略图
- 区域描边

以下内容禁止烘焙进图片：

- 商圈名称
- 商圈数量
- 金额
- 客流
- 租金
- 等级
- 评分
- 状态数字
- 今日机会正文

这样后续数据变化不会导致重新出图。
