# 餐饮 V2 城市页参考坐标规范 1.1

## 1. 两套坐标必须分开

唯一视觉母版仍然是用户确认的 **864 × 1536 成品图**。

但这张图的 864 × 1536 是截图/美术像素，不等于 Android WebView 的 CSS px。

当前正式换算基准：

- 美术母版：864 × 1536 px
- CSS 参考视口：432 × 768 CSS px
- 基准换算：0.5

因此禁止再把母版上的 94px HUD 直接写成 94 CSS px。

## 2. 母版视觉区间

| 区域 | 美术高度 | 0.5折算视觉高度 |
| --- | ---: | ---: |
| Global HUD | 94 | 47 |
| 城市头图区 | 135 | 67.5 |
| 五项筛选 | 66 | 33 |
| 地图主舞台 | 657 | 328.5 |
| 商圈详情 Sheet | 435 | 217.5 |
| Global Nav | 149 | 74.5 |

## 3. 正式运行目标

考虑 48dp 触摸区和实际中文排版后，432×768 CSS 参考视口使用：

- HUD：52
- Hero：68
- Filters：48
- Detail Sheet：218
- Global Nav：74
- 地图：吃掉剩余高度；低矮屏最低可压到约160

这不是重新设计，而是在保证可点和可读的前提下尽量贴近母版比例。

## 4. 手机适配

### >=400 CSS px 宽

保持 HUD 三段单排。

### <400 CSS px 宽

HUD 只把同一套字段重排成两行，总高度约88，不建立第二套 HUD。

### 高度差

不同比例手机增加或减少的主要纵向空间全部交给地图：

- Hero 不无限变高
- Filter 不变两排
- Detail 不被拉长
- Nav 不被拉长
- 地图承担弹性

## 5. 城市 Hero

成品图只有一个右侧商圈总览卡。

正式实现同步为：

- 左：城市图标
- 中：城市地图标题 + 一行副标题
- 右：商圈总数 + 已开店数量

不再把“总商圈”和“已开店”拆成上下第二行两张卡。

## 6. 详情 Sheet

详情必须保持母版密度：

- 顶部：缩略图 + 商圈名/状态 + 查看房源
- 中间：六指标单排
- 底部：今日机会三卡单排

禁止恢复成六指标 3×2 或把今日机会卡放大成列表页尺寸。

## 7. 字体

字号依据母版视觉像素折算后再做小范围可读性修正。

典型运行字号：

- HUD标题 12
- HUD时间 16
- 页面标题约24
- 页面副标题约12
- 筛选约11
- 商圈标签标题 11
- 详情标题 16
- 详情正文 10
- 指标数字 12
- 今日机会标题 14
- 底栏 13

统一使用 500/600/700/800/900 字重。

## 8. 不允许的做法

- 把截图像素直接当 CSS px
- 整页 transform: scale()
- 为某一台手机写一套独立 UI
- 地图、按钮、文字非等比拉伸
- 六指标改回两行
- Hero 改回两排摘要卡
- 关键数字省略号
