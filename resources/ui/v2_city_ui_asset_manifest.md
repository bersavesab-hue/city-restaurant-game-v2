# V2城市地图UI资源替换清单

## 本轮替换目标
- 顶栏：更换为统一蓝色玻璃质感组件，避免拼接感。
- 底栏：采用城市经营五入口统一图标组件。
- 地图：使用完整比例底图，不裁剪主体区域，仅按屏幕比例缩放。
- 区域标签：CBD、大学城、夜生活、老城、水岸休闲统一视觉语言。
- 信息卡：统一圆角、阴影、颜色体系。

## 资源目录规划
resources/ui/city/
- map/
- topbar/
- bottombar/
- zone_labels/
- stat_icons/
- buttons/

## 接入原则
1. 删除旧占位UI资源引用。
2. 保留动态数据接口，不把地图文字和数据写死。
3. 图片资源只负责显示，不承担逻辑。
4. 完成后再进行Android全屏适配。
