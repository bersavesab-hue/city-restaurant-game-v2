# UI V2 城市地图

城市页以用户确认的 864×1536 成品图为纵向母版。六段在该尺寸下分别为 HUD 94、Hero 135、筛选 66、地图 657、详情 435、导航 149。手机视口使用 CSS grid 和相对单位分配空间，地图作为可裁切的世界层；安全区域并入 HUD 与底栏，页面不产生横向滚动。

## 静态视觉层

- `resources/ui-v2/illustrations/city-map-master.webp` 是地图底图，来自提供的无字地图。五张商圈详情图与今日机会图集分别存放，避免重复放大地图造成模糊。
- `resources/ui-v2/icons` 按组件保存天气、资金、皇冠、星级、五区标识、底栏、地图控制和六项指标图标。SVG 用于规则图形，WebP 用于用户提供的画面素材。
- `CityFrame.js` 固定五区的标签槽位、轮廓、筛选、指标、机会卡与对话框。`city-frame.css` 只规定外观、层级和响应尺寸；图片里不写游戏数字、地名或状态。

## 动态数据与交互层

- `LiveUiModel.js` 读取商圈、真实房源、门店、连锁、账户、评价、时间与事件。筛选数量、区域数、商圈统计、详情指标、今日机会、顶部资金与等级均随游戏状态刷新。
- `LiveUiBinding.js` 把模型写入对应 DOM 槽位；地图筛选/选区、缩放/拖拽/复位、房源与机会列表、HUD 时间控制以及顶部/底栏信息入口都在此连接。
- `AndroidBootstrap.js` 只挂载一套 `AppShell`、一套城市画面与状态绑定。房源和机会详情读取真实数据，不把示例截图中的数字写进模型。

## 适配与验证

布局在 864×1536、691×1536、390×844 和 360×800 的视口校准；原图在地图世界层以 864:660 比例完整显示，窄屏空隙由模糊底图填充。地图标签保持在可见范围，右侧控制组与水岸标签留出间隔，弹窗独立滚动。运行 `npm run test:ui-v2:framework` 与 `npm run build:android-js` 可检查契约和离线素材链。
