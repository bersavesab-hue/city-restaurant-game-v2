1. 锁定框架。
2. 锁定组件盒。
3. 锁定字体与排版。

当前不接正式地图、不接正式图标、不接业务动态数据。

## 规则

- 图片以后只能填进既定盒子，不能反向撑开盒子。
- 文本以后只能填进既定文字区域，不能改变一级区域高度。
- 不允许页面自行定义字号、字重、圆角、图标尺寸。
- 不允许因为手机变窄就把 HUD 改成两排。
- 不允许整页 transform: scale()。
- 不允许恢复已删除的旧城市 UI、旧视觉坐标、旧 Atlas 或旧资源绑定。

当前运行 APK 展示的是框架校准稿，示例文字只用于确认字体和盒子位置，不代表正式动态数据已经接入。
